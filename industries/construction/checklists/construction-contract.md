# 施工合同审查清单（含分包）

- [ ] 承包人资质与工程规模匹配；总包、分包各自资质在有效期内，安全生产许可证有效。
- [ ] 不存在转包、违法分包、挂靠：劳务作业是否发包给有资质企业；专业分包是否经发包人同意且非主体结构。
- [ ] 合同价款形式明确：总价、单价、成本加酬金；暂估价、暂列金额的约定与调整机制。
- [ ] 工期条款：开工条件、竣工日期、顺延情形与程序（书面 + 时限，逾期看 I-6）。

- [ ] 进度款支付节点、比例、逾期利息；结算期限与审计前置是否构成付款条件（审计或财政评审结论为结算依据而超期未出具、或与合同约定明显不符的，解释二第13条准许申请工程造价司法鉴定；未约定以审计结论为结算依据的，发包人不得单方主张）。
- [ ] 质量标准、验收程序、保修范围与保修金返还节点。
- [ ] 争议解决：管辖或仲裁机构明确；约定境外仲裁或适用外国法的看 H4 并升级。
- [ ] 实际施工人风险：存在层层分包的，提示实际施工人直接索偿风险并固定已付款证据。
