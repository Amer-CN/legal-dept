## 结算与优先受偿

- [ ] 进度款、结算款的应付时点已梳理成时间轴；逾期款项先发书面催告并留痕。
- [ ] 优先受偿权已提示：工程性质是否适宜折价拍卖；行使期限已核验——解释一第41条「最长不得超过十八个月，自发包人应当给付建设工程价款之日起算」，解释二第21条约定变更给付日期的自变更后应当给付之日起算（法定上限不因约定延长），逾期失权（锚点 I-4；逐项见本包 `claim-limitation.md`）。
- [ ] 结算资料齐全：签证单、变更单、会议纪要、竣工图、验收记录；缺失项列清单补救。
- [ ] 发包人以审计、内部审批为由拒付的，审查该约定是否构成有效付款条件（已核验：解释二第13条——约定以审计结果或财政评审结论确定工程价款，非因承包人原因未在合理期限内出具、或承包人有证据证明与合同约定明显不符的，准许承包人申请工程造价司法鉴定；该合理期限有约定从约定，无约定由法院综合工程规模、造价金额、复杂程度确定且不得超过承包人提交竣工结算文件之日起一年；未约定以审计结果或评审结论确定价款的，发包人请求据此确定的不予支持）。
- [ ] （未覆盖项）工程款债权转让的：是否已书面通知发包人并留存签收凭证；拟转让的债权是否已有效存在（已完工程质量合格即可，不以价款金额已结算确定为前提）；是否逐一核对合同约定、债权性质与法律规定三类禁止转让情形。
- [ ] （未覆盖项）以房抵顶工程款或以承债方式结算的：房屋是否已过户并实际交付占有使用；第三人出具付款承诺的，其措辞是保证还是债务加入，有无免除原债务人义务的约定。
- [ ] （未覆盖项）发包人一并主张担保责任的：主合同解除后担保是否仍及于债务人应承担的民事责任，担保合同有无相反约定。

## 竣工验收与备案

- [ ] 竣工验收程序完整，未经验收不得擅自使用（擅自使用看 I-5，定级高）。
- [ ] 验收备案文件已向属地住建部门核实清单并留存回执。
- [ ] 保修期起算点、保修范围、保修金比例与返还节点明确。
- [ ] （未覆盖项）验收是否合格，认定依据是建设单位自己出的那份验收报告；备不备案、办没办备案手续，都不影响这一认定。发包人未同意、由承包人单独拉人组织的验收，不产生上述效力。
- [ ] （未覆盖项）竣工验收前提条件是否一并核对：合同约定的工程款是否已按约支付、施工单位是否已签署工程质量保修书。
- [ ] （未覆盖项）保修期起算点是否按竣工验收合格之日逐项核定，有无把保修期与缺陷责任期混用（两者期限与依据不同），有无以缺陷责任期口径倒推保修期起算。
