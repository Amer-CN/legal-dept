## 结算与优先受偿

- [ ] 进度款、结算款的应付时点已梳理成时间轴；逾期款项先发书面催告并留痕。
- [ ] 优先受偿权已提示：工程性质是否适宜折价拍卖；行使期限已核验——解释一第41条「最长不得超过十八个月，自发包人应当给付建设工程价款之日起算」，解释二第21条约定变更给付日期的自变更后应当给付之日起算（法定上限不因约定延长），逾期失权（锚点 I-4；逐项见本包 `claim-limitation.md`）。
- [ ] 结算资料齐全：签证单、变更单、会议纪要、竣工图、验收记录；缺失项列清单补救。
- [ ] 发包人以审计、内部审批为由拒付的，审查该约定是否构成有效付款条件（已核验：解释二第13条——约定以审计结果或财政评审结论确定工程价款，非因承包人原因未在合理期限内出具、或承包人有证据证明与合同约定明显不符的，准许承包人申请工程造价司法鉴定；该合理期限有约定从约定，无约定由法院综合工程规模、造价金额、复杂程度确定且不得超过承包人提交竣工结算文件之日起一年；未约定以审计结果或评审结论确定价款的，发包人请求据此确定的不予支持）。
- [ ] （未覆盖项）工程款债权转让的：是否已书面通知发包人并留存签收凭证；拟转让的债权是否已有效存在（已完工程质量合格即可，不以价款金额已结算确定为前提）；是否逐一核对合同约定、债权性质与法律规定三类禁止转让情形。
- [ ] （未覆盖项）以房抵顶工程款或以承债方式结算的：房屋是否已过户并实际交付占有使用；第三人出具付款承诺的，其措辞是保证还是债务加入，有无免除原债务人义务的约定。
- [ ] （未覆盖项）发包人一并主张担保责任的：主合同解除后担保是否仍及于债务人应承担的民事责任，担保合同有无相反约定。
- [ ] （未覆盖项）工程总承包项目是否分项计列费用：勘察设计费、建筑安装工程费、设备购置费与总承包其他费即便投标时笼统报价，也按该底层逻辑分别核定；总价合同按约完工后固定总价部分不再重新计算工程量与费用，重新审价限于暂列费用、合同约定的价款调整与索赔部分。
- [ ] （未覆盖项）价款构成中质量保证金与工程款分项处理：预扣的质量保证金属工程价款的一部分，其返还自身约定返还期限约束，不与缺陷责任期混算；扣留与返还的时点应各自单列计算。
- [ ] （未覆盖项）合同无效或中途解除情形下的质量责任与保修义务是否分项认定：施工质量责任与保修义务各有依据，二者不可相互替代或折算。
- [ ] （未覆盖项）以行使期限与起算点主张优先受偿权前，先核对适用的法律口径与起算规则（不同口径下起算点不同，不得沿用旧规则），并就欠付工程款的付款时间、支付方式、支付条件有无事后协商变更一并核实。
- [ ] （未覆盖项）合同约定以第三方审计或审价结论结算的，核对约定主体与范围是否落在行政审计要件内：仅约定由造价咨询机构或主管部门委托审价，不等于约定了以审计结论作为结算依据。
- [ ] （未覆盖项）验收适用规则是否按工程类型分别确定：公路分交工与竣工验收两阶段并有试运营期要求，铁路分静态、动态、初步、安全评估与正式验收多阶段，机场分竣工预验收、竣工验收（另有行业验收），未达条件即主张结算或付款条件成就的不能成立。
- [ ] （未覆盖项）未竣工未验收即申请结算的，核对未办理交接与工程未完工的原因归属：原因在发包人一方（如强制撤场、恶意驱逐）的，由发包人举证。
- [ ] （未覆盖项）以政府审计结论结算的价款争议中，核对双方有无另行书面确认工程量或价款的行为：结算报告签署后又参加主管部门委托的审核并签字确认的，该工程量视为被重新确定，结算价款应相应调整。
- [ ] （未覆盖项）剩余价款按完工比例折算前，核对双方是否已书面确认完工比例；未确认而径行按比例折算的，其比例缺乏事实依据。

## 竣工验收与备案

- [ ] 竣工验收程序完整，未经验收不得擅自使用（擅自使用看 I-5，定级高）。
- [ ] 验收备案文件已向属地住建部门核实清单并留存回执。
- [ ] 保修期起算点、保修范围、保修金比例与返还节点明确。
- [ ] （未覆盖项）验收是否合格，认定依据是建设单位自己出的那份验收报告；备不备案、办没办备案手续，都不影响这一认定。发包人未同意、由承包人单独拉人组织的验收，不产生上述效力。
- [ ] （未覆盖项）竣工验收前提条件是否一并核对：合同约定的工程款是否已按约支付、施工单位是否已签署工程质量保修书。
- [ ] （未覆盖项）保修期起算点是否按竣工验收合格之日逐项核定，有无把保修期与缺陷责任期混用（两者期限与依据不同），有无以缺陷责任期口径倒推保修期起算。
- [ ] （未覆盖项）专业工程与专项验收是否齐备：缺少各类专项验收合格文件的不具备组织竣工验收的条件；特殊建设工程未经消防设计审查或验收不合格的不得施工、不得投入使用。
- [ ] （未覆盖项）交付使用与竣工日期的关系是否核实：仅接收而未曾使用、仍保留原状的，不能以转移占有之日认定竣工日期（如承包人擅自撤场后发包人迫于无奈接收的情形）。
- [ ] （未覆盖项）工程总承包项目是否两项质量责任并查：施工质量合格与产品性能达标各自独立，试车、试运行不等于质量合格的认定；验收合格也不等于工程实际合格，合理使用寿命内因质量问题受损的仍可向责任者索赔。

## 安全生产

> 本节同时供 `compliance-counsel` 安全生产条件自查加载；资质与许可证有效期同步核对 `checklists/bidding-compliance.md`。

- [ ] 施工单位安全生产许可证有效；项目经理与专职安全员持证在岗。
- [ ] 安全技术交底、隐患排查记录留痕；分包单位安全协议已签署。
- [ ] 发生事故即按 I-7 定级极高：保护现场、报告主管部门、同步建议外部律师介入；不得隐瞒不报、破坏现场。
- [ ] （未覆盖项）专业分包与劳务分包相对方的安全生产条件与相应资质是否核验；把工程发包给安全生产条件不达标或不具备相应资质的主体施工的，一旦发生生产安全事故，发包人可能要对事故损害承担连带的赔偿责任。
- [ ] （未覆盖项）工程总承包模式下的安全生产责任分配是否核查：实行施工总承包的由总承包单位对施工现场安全生产负总责，分包单位服从其管理并对分包工程安全生产承担连带责任；由设计单位单独承接总承包的，是否建立施工管理部门并实际履行对施工过程的管控义务，仅承担设计分包的不负同等安全责任。
