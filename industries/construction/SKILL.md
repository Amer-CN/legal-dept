# 建筑工程行业包（construction）

- 版本：v1.0
- 知识截至日期：2026-09-14
- 更新归属：挂载方的法务部维护人（未指定时默认为使用者本人）
- 过期预警：知识截至日期超 6 个月未复核，引用本包的产出头部自动追加「知识可能过期，请复核」

> 本包不改变四级风险标尺与三条贯穿硬规则，只补充判定锚点与检查项。总纲分诊到岗位后，岗位按本包加载行业检查项；未挂载本包时，岗位对行业事项按「待核实」处理并提示用户向行业主管部门核实。

## 1. 适用范围

覆盖：招投标合规审查、施工合同与分包合同审查要点、工期签证与索赔时效管理、农民工工资支付合规、工程款结算与优先受偿提示、竣工验收与备案、安全生产责任提示。

不覆盖：工程造价鉴定、工程质量鉴定、图纸与技术方案审查、出庭代理、刑事辩护——超出部分走《案件转介单》（模板见 `shared/templates/referral-form.md`）。

## 2. 行业特有风险锚点（前缀 `I-`，引用时注明「行业包补充锚点」）

- I-1 无资质、超资质承揽，转包或违法分包，挂靠施工 → 极高（合同无效风险，直报并建议外部律师立即介入）。
- I-2 依法必须招标的项目未招标、规避招标、围标串标 → 极高。
- I-3 未开设农民工工资专用账户、未实行总包代发、未存储工资保证金 → 高，拒不整改或引发群体讨薪的按极高。
- I-4 发包人拖欠工程款且未及时主张优先受偿 → 高（行使期限有法定限制，逾期失权，要点细节标「待核实」并立即提示用户核实）。
- I-5 未经验收擅自使用建设工程 → 高（质量责任倒置风险）。
- I-6 签证、索赔逾期未提出 → 中，临近失权期限的按高（期限以合同通用条款与示范文本为准，标「待核实」）。
- I-7 发生生产安全事故或存在重大安全隐患 → 极高（行政、刑事、信用三重后果）。

## 3. 岗位加载指引

- 合同审查（施工总承包合同、分包合同、EPC 合同）→ `contract-counsel` + 本包 `checklists/construction-contract.md`。
- 招投标文件、资质证照 → `compliance-counsel` + 本包 `checklists/bidding-compliance.md`；跨行业通用的招投标程序合规清单见 `shared/checklists/bidding-compliance.md`（本包内为建工特有细节，通用规则以通用清单为准）。
- 安全生产条件（许可证、持证在岗、安全交底、隐患排查）→ `compliance-counsel` + 本包 `checklists/completion-settlement-safety.md`“安全生产”节，并同步核对 `checklists/bidding-compliance.md` 中的资质与许可证项。
- 农民工工资、劳务用工 → `employment-counsel` + 本包 `checklists/migrant-wage.md`。
- 工程款催收、结算争议、索赔谈判、已进入诉讼仲裁 → `dispute-counsel` + 本包 `checklists/completion-settlement-safety.md`。
- 多岗交叉（如分包合同无效又拖欠农民工工资）由总纲汇办，取更保守结论。

## 4. 属地差异提示

- 招投标监管与交易平台规则向属地发改部门、住建部门、公共资源交易中心核实。
- 工资保证金标准、专用账户开设要求向属地人力资源和社会保障部门核实。
- 施工许可、竣工验收备案、安全生产标准化向属地住房和城乡建设部门核实。
- 地方另有清欠、信用评价（建筑市场黑名单）规定的，向属地住建部门核实。
