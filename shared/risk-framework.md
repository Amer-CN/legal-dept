# 风险分级框架（全套装唯一标尺）

- 版本：v1.0
- 知识截至日期：2026-09-14
- 更新归属：本文件由挂载方的法务部维护人负责复核更新（挂载时在 README 指定责任人，默认由使用者本人担任）
- 过期预警：知识截至日期超 6 个月未复核，引用本文件的产出头部须自动追加「知识可能过期，请复核」警示

## 1. 标尺定义

全套装只使用四级风险术语：**低 / 中 / 高 / 极高**。

禁止事项：

- 禁用一切 0-100 量化打分，禁用「风险指数」「安全评分」类表述。
- 禁用颜色词落盘（「绿/黄/红」仅为分诊口头语，不写入任何产出物、模板、台账）。
- 禁用无判定理由的等级标注：定级必须写明「依据锚点」。

定级输出格式固定为：

```
风险等级：<低/中/高/极高>
判定锚点：<命中的锚点条目编号 + 一句话事实>
```

## 2. 判定锚点

定级方法：先看「最不利后果」，再看金额与主体，最后看可逆性。命中任一更高等级锚点即取该等级。

### 2.1 极高

- E1 涉及刑事风险（可能被追究刑责、可能被采取强制措施、可能涉嫌单位犯罪）。
- E2 可能触发停业、吊销许可、市场禁入等不可逆的行政后果。
- E3 涉及群体性事项（劳动者人数达到或超过十人、批量客户投诉、群体诉讼）。
- E4 可能丧失公司控制权、核心资产、核心知识产权归属。
- E5 争议标的达到或超过公司注册资本，或达到或超过上一年度营业收入的一定比例（比例由挂载方在台账首页写明，未写明时按从严处理）。
- E6 诉讼时效或除斥期间即将届满且错过即不可逆。
- E7 涉及上市公司信息披露义务、重大资产重组、监管已介入或已立案调查。
- E8 涉及跨境制裁、出口管制、数据出境安全评估等监管红线。

### 2.2 高

- H1 单份合同金额重大，或约定无限责任、无上限赔偿、排他性义务、单方解释权。
- H2 涉及劳动关系单方解除、竞业限制、股权激励、批量用工调整。
- H3 涉及股权、知识产权归属或核心商业秘密的处分。
- H4 管辖约定在异地或境外，或约定境外仲裁、适用外国法。
- H5 需前置审批、备案、资质许可方可实施的事项。
- H6 相对方为政府机关、国有企业、上市公司或行业头部主体。
- H7 事项可能被媒体报道、影响商誉或影响后续融资。

### 2.3 中

- M1 使用公司范本但对方提出实质性条款修改。
- M2 金额中等、一次性交易、后果可谈判修复。
- M3 常规劳动争议、常规债权催收、常规合同违约沟通。
- M4 存在时效压力但仍在可控期限内（可通过主张权利方式中断）。

### 2.4 低

- L1 直接使用公司范本且无实质性修改。
- L2 金额小、即时履行完毕、无后续义务。
- L3 纯咨询、流程性问答、对既有结论的复述与整理。

## 3. 定级程序后果（程序随等级变化，不只是标签）

| 等级 | 办理方式 | 复核要求 | 归档 |
| --- | --- | --- | --- |
| 低 | 承办岗直接办理 | 承办岗自查，产出标注「本件为低风险，未过总监复核」 | 台账简记 |
| 中 | 承办岗办理 | 总纲自查（简复核），产出标注「已过简复核」 | 台账登记 |
| 高 | 承办岗办理 + 强制复核 | 总监复核；未复核则产出头部醒目标注「未经复核」 | 台账登记 + 交付物留存 |
| 极高 | 承办岗办理 + 强制复核 + 直报 | 总监复核，并同时出具升级建议（转人工律师/外部律所） | 台账登记 + 交付物留存 + 升级记录 |

## 4. 分级不确定时的处理

- 不确定即向上取整：不确定是「中」还是「高」，取「高」。
- 分级依据不足时，先补关键事实再定级；补不到事实的，按最不利假设定级并写明「按最不利假设定级」。
- 定级可随事实变化调整，调整后必须重走对应的复核门，并在台账留痕。

## 5. 与分诊口头语的关系

分诊对话中可以用「绿/黄/红」沟通，但落盘一律回写四级术语：绿=低、黄=中、红=高或极高。落盘出现颜色词视为未完成。
