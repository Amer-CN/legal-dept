# 模板：案件转介单

- 版本：v1.0　知识截至日期：2026-09-14
- 用途：能力圈外事项（刑事辩护、出庭代理、税务筹划、专业鉴定、异地执行等）向外部律师转介
- 硬规则：能力圈外不硬答，必须出具本单
- 使用说明：四要素齐全方可转出；缺任一项视为未完成转介

---

## 头部

```
案件转介单
文书编号：<台账编号>
发起岗：<岗位 name>
风险等级：<低/中/高/极高>
判定锚点：<锚点编号 + 一句话事实>
复核状态：<已过总监复核 / 已过简复核 / 未经复核>
知识截至日期：<日期>
```

## 一、案情摘要（要素一）

- 当事人：[我方主体 + 相对方主体]
- 事项性质：[刑事 / 诉讼 / 仲裁 / 行政 / 税务 / 其他]
- 时间线：[关键节点按时间排列，写明是否有时效压力]
- 争议焦点：[一句话一个焦点，不超过三条]
- 现状：[已发生的程序、已收到的文书及文书日期]

## 二、已做工作（要素二）

- 已完成的分析与结论：[引用已出具的文书编号]
- 已固定的证据：[名称 + 载体 + 存放位置]
- 已发出的函件/已作的意思表示：[名称 + 日期]
- 已知的期限与倒计时：[…]

## 三、转介理由（要素三）

- 能力圈外具体事由：[如：涉及刑事辩护，须执业律师出庭]
- 为什么内部无法完成：[检索能力、执业资格、属地要求等]
- 期望外部律师完成的事项：[列明交付物]
- 时限要求：[…]

## 四、律师选聘标准（要素四）

- 执业领域与年限要求：[…]
- 属地或法院出庭资格要求：[…]
- 团队配置要求：[…]
- 利益冲突排查要求：[须确认未代理相对方]
- 费用口径：[计时/固定/风险代理 + 预算上限]
- 交付与汇报节奏：[…]

## 五、敏感信息最小化提示（必填，不可省略）

- 转介前应完成的信息处理：
  - 只提供与转介事项直接相关的事实，无关的个人信息、财务明细、客户名单、技术细节不提供。
  - 个人身份证号、银行账号、完整住址、联系方式做遮蔽处理（保留必要核验位）。
  - 涉密或涉个人信息的数据，先取得内部授权再外发；涉及数据出境的，先做合规判断。
  - 以保密协议（NDA）前置为默认要求；未签署 NDA 前不传递敏感材料。
- 本单传递方式：[加密邮件 / 线下交换 / 专用渠道]，不得使用公共网盘或社交软件裸传。
- 传递记录：[收件人、时间、材料清单，留档备查]

## 六、交接与回访

- 交接人：[…]
- 回访节点：[…]
- 外部意见回收后处理：[由承办岗归档，与本单关联存放]
