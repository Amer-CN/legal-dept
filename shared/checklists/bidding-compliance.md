## 一、强制招标识别（先定范围，再谈程序）

- [ ] 标的是否属于依法必须招标的范围：项目性质（全部或部分使用国有资金、使用国际组织或外国政府资金等）、资金来源与金额规模是否达到必须招标的标准与限额（标准与限额以现行规定与属地口径为准，标「待核实」）。
- [ ] 是否属于依法可以邀请招标、可以不招标或者竞争性谈判、询价、单一来源等例外情形；例外情形的适用条件与审批（核准）手续是否齐备。
- [ ] 有无规避招标迹象：化整为零、虚假招标、明招暗定、以邀请招标替代公开招标、以战略合作或框架协议名义规避、以关联方代持或分包方式实质定向。
- [ ] 采购方式的选择依据有无书面留痕（制度依据、审批记录、选择理由说明）。
- [ ] 不属于强制招标范围的，是否仍受本企业采购制度、上级单位要求或行业监管规则约束（标「待核实」）。

## 二、前置文件齐备性

- [ ] 项目立项、可行性研究、投资或预算批复文件齐备，且与本次采购内容、金额对应。
- [ ] 招标文件（含资格预审文件）已按规定审阅留痕。
- [ ] 资格预审文件、公告与文件发售记录、答疑与澄清纪要齐备。
- [ ] 开标记录、评标委员会组成与评标报告、评标结果公示记录齐备。
- [ ] 中标候选人公示、中标通知书、未中标通知齐备。
- [ ] 涉及代理机构的，委托代理合同与代理机构资质、回避情况齐备。
- [ ] 招标投标全过程留痕完整可追溯（公告、发售、答疑、开标、评标、定标、通知的时间与文件对应）。

## 三、一致性核对（招标文件 ↔ 投标文件 ↔ 中标通知书 ↔ 合同）

- [ ] 合同标的、数量、价款（含暂估与调整机制）、工期或交付期限、质量标准、验收与付款节点、违约责任等**实质性条款**，与招标文件、投标文件、中标通知书逐项对应。
- [ ] 有无中标后另行签订背离招标文件实质性内容的协议（含补充协议、会议纪要、往来函件、口头变更的书面化文件）。
- [ ] 有无中标后以变更方式实质性降低质量标准、延长工期或提高价款。
- [ ] 投标主体的名称、资质与中标主体、合同签署主体一致；不一致的（如中标后更换主体、由关联方签署）有无合法依据与审批留痕。
- [ ] 参与投标的各方之间有无围标串标迹象：意思联络、陪标、轮流中标、报价异常一致、投标文件雷同。
- [ ] 招标文件有无排斥潜在投标人的条款：不合理资质门槛、地域限制、特定业绩指向。

## 四、三重一大决策衔接（决策文件与采购程序对齐）

- [ ] 金额、期限、担保方式是否触发本企业「三重一大」决策门槛（门槛见组织基线档案 `shared/templates/org-profile.md` 第二节；未采集时不得推定「未达门槛」，按「不确定即向上取整」处理）。
- [ ] 是否履行集体决策程序：党委前置研究（如适用）、董事会或总经理办公会决议、涉及职工利益时的职工代表大会程序。
- [ ] 决策文件的签署主体、金额、期限、交易对方与合同逐项对应；有无先签后议、倒签日期、以会议纪要替代决议的情形。
- [ ] 招投标程序与决策程序的时间先后是否合理：有无先定标、后补程序，或决策文件缺失而合同已签署。
- [ ] 涉及国有资产交易的，是否满足进场交易、公开挂牌、资产评估及其核准或备案、信息披露要求（应评估未评估、应进场未进场、以协议转让规避挂牌为重点核查，标「待核实」）。
